# Changelog

Release history for Ferric. Each version records verified shipped changes; earlier installers keep their original behavior.

## Downloads and Installation

- **Included:** Per-user Windows x64 MSI installer (`ferricsetup-vX.Y.Z.msi`), portable ZIP archive (`Ferric-vX.Y.Z-windows-x86_64.zip`), `SHA256SUMS.txt`, product icons, embedded Inter v4.1 + Makepad desktop fonts, Start Menu shortcut (`AppUserModelID: Raflyf.Ferric`), and license notices.
- **Per-user setup:** Installs into `%LOCALAPPDATA%\Programs\Ferric` without administrator privileges while keeping user data in `%LOCALAPPDATA%\LivelyDesk\Ferric\data\ferric.db`.
- **Verified updates:** Built-in `Check for Updates` and optional startup update prompt verify `SHA256SUMS.txt` from official GitHub Releases and re-verify the SHA-256 digest immediately before launching `%SystemRoot%\System32\msiexec.exe`.

### Security & Hardening

- **DPAPI Credential Protection, Zeroization & Fail-Closed CSPRNG (`crates/ferric-core/src/secrets.rs`):** Account OAuth tokens, refresh tokens, cookies, SAPISID, and Subsonic passwords are encrypted at rest with Windows DPAPI (`dpapi:v1:` via `crypt32.dll` + fail-closed `BCryptGenRandom` with zero non-CSPRNG fallback), zeroized in memory on sign-out and temporary buffer drop, never written to `%TEMP%`, and protected with SQLite `PRAGMA secure_delete = ON` + `VACUUM` after plaintext migration.
- **Win32 Anti-Injection, Process Mitigations & CDP Hardening (`apps/ferric-desktop/src/shell.rs`, `spotify_browser_login.rs`, `google_login.rs`):** Enforces `/DEPENDENTLOADFLAG:0x800`, `SetDllDirectoryW("")`, `SetDefaultDllDirectories(LOAD_LIBRARY_SEARCH_SYSTEM32)`, `HeapSetInformation(HEAP_ENABLE_TERMINATION_ON_CORRUPTION)`, and `SetProcessMitigationPolicy`; pins Spotify Web CDP `--remote-allow-origins` to exact loopback `http://127.0.0.1:{port}` with strict `Origin` header, `https://open.spotify.com` origin & `secure` cookie verification, and RAII temp cleanup.
- **Strict WebView2 Sandboxing & SSRF Defense (`video_player.rs`, `google_login.rs`, `subsonic.rs`, `oauth.rs`, `public_sync.rs`):** Applies strict CSP, `no-referrer`, disables DevTools/context menus/host objects/web messages/accelerator keys/autofill/swipe navigation, denies all permissions, blocks popup windows, enforces strict `NavigationStarting` URL allowlists, blocks SSRF/metadata/private IP/redirect chains (`max_redirects(0)`), enforces 128-bit constant-time CSRF `state` verification on OAuth callbacks, and redacts secrets from `Debug` output.
- **TOCTOU-Safe Updater & Verified Media Cache (`shell.rs`, `updater.rs`, `ytmusic.rs`, `lyrics.rs`):** Holds a `FILE_SHARE_READ` lock while streaming SHA-256 verification right before invoking `%SystemRoot%\System32\msiexec.exe` (keeping the lock until installer exit), verifies container magic headers and byte counts on stream cache writes/hits, enforces HTTPS-only allowlisted URLs, and bounds import file sizes (`M3U`/`CSV`/`APO`/theme JSON).
- **Reproducible Anti-RE PE Hardening, Zero Debug Hooks & SHA-Pinned CI (`Cargo.toml`, `scripts/build-release.ps1`, `.github/workflows/*.yml`, `scripts/verify_pe_hardening.py`):** Compiles releases with `lto = "fat"`, `codegen-units = 1`, `strip = "symbols"`, `panic = "abort"`, `/GUARD:CF`, `/CETCOMPAT`, `/DYNAMICBASE`, `/HIGHENTROPYVA`, `/NXCOMPAT`, `/DEPENDENTLOADFLAG:0x800`, `/DEBUG:NONE`, `/NOCOFFGRPINFO`, `/BREPRO`, `subst`, `--remap-path-prefix`, and `/d1trimfile`; all dev CLI overrides and diagnostic env logs are gated strictly under `#[cfg(debug_assertions)]`; verified by CI for PE32+ GUI, zero RWX sections, populated `LOAD_CONFIG` CFG table, `DependentLoadFlags=0x0800`, `CETCOMPAT`, `BREPRO`, and zero PDB or host path leaks, with 40-char SHA-pinned GitHub Actions and least-privilege split build/release jobs.
