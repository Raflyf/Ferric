Ferric — Hi-Fi Desktop Music Player

Ferric plays your local lossless and lossy audio library (FLAC, MP3, AAC/M4A, ALAC, Ogg, Opus, WAV, AIFF) alongside optional online music discovery using 100% native Rust audio decoding (Symphonia + pure-Rust Opus + Rubato resampler + dual-deck Bass-Swap Automix + 10-band parametric Biquad EQ).

Per-user Windows installation:
Install Ferric for your Windows user under %LOCALAPPDATA%\Programs\Ferric. No administrator rights are requested. Setup adds a Start menu shortcut (AppUserModelID: Raflyf.Ferric), an Add/Remove Programs entry, and an option to launch Ferric on finish. Upgrading preserves your local SQLite library database (%LOCALAPPDATA%\LivelyDesk\Ferric\data\ferric.db), equalizer presets, and Appearance / AMOLED Black / Native Acrylic theme settings.

Network, Local IPC & Privacy Notice:
- Setup itself makes no network requests.
- By default, Ferric performs one lightweight HTTPS request on startup to https://api.github.com/repos/Raflyf/Ferric/releases/latest to check for newer stable releases (User-Agent includes only the app version, never library paths or preferences). You can disable automatic startup checks at any time from the update popup or inside Settings > Storage.
- On normal startup, the Home discovery feed loads personalized YouTube Music shelves (music.youtube.com) and album artwork thumbnails (*.googleusercontent.com, *.ggpht.com, i.ytimg.com). When you are signed in to Spotify, Home Recommended Stations also query Spotify Web / Pathfinder API (clienttoken.spotify.com, api-partner.spotify.com) and load cover thumbnails (*.scdn.co, *.spotifycdn.com).
- Updates are never downloaded or installed silently without your click. When you click Update Now, Ferric downloads SHA256SUMS.txt and ferricsetup-vX.Y.Z.msi exclusively from official GitHub hosts, re-verifies the exact SHA-256 digest right before launching %SystemRoot%\System32\msiexec.exe, and deletes temporary files on any mismatch.
- Optional synced lyrics lookup queries open lyrics services (lrclib.net / api.lyrics.ovh) only when no local sidecar .lrc file or embedded tag lyrics are found.
- Public playlist URL import, Spotify Direct OAuth 2.0 PKCE (Premium) or Spotify Web Sign-In read-only metadata sync, OpenSubsonic/Navidrome sync, and Google WebView2 sign-in operate on user action; stored tokens, cookies, and passwords are encrypted at rest on Windows using DPAPI (CryptProtectData).
- Optional Discord Rich Presence communicates locally over the Windows Discord desktop IPC pipe (\\.\pipe\discord-ipc-*) only when enabled in Settings > Integrations.
- Optional Ferric Connect LAN peer discovery (UDP port 43821) starts only when you open Settings > Connect.

Unsigned builds prior to code signing activation:
Keep Windows security protections enabled and obtain releases only from https://github.com/Raflyf/Ferric/releases verified against SHA256SUMS.txt.
